# 全局滚动条样式优化

## 目标
统一全应用滚动条(侧栏、Git、设置、弹窗、终端、Monaco)为精致细滚动条,深浅主题一致,修复现有几个问题。

## 优化点

### 1. 宽度统一为 8px,统一令牌化
- 新增令牌 `--scrollbar-size: 8px`(深浅主题一致)
- 全局 `::-webkit-scrollbar` 从 10px → 8px
- Monaco 编辑器:在 `getEditorOptions` 加 `scrollbar: { verticalScrollbarSize: 8, horizontalScrollbarSize: 8 }`(当前默认 14px,偏粗)
- 保留特殊条:`.tabs`(横向 3px)、`.breadcrumb`(隐藏 0px)、`.tabs--wrap`(纵向 3px)不变

### 2. 修复颜色不一致
- **深色**:当前 `--scrollbar-thumb-active`(#BFBFBF,比 hover 还浅)反直觉 → 改为 hover 最深、active 更深的标准递进
- **浅色**:三态颜色完全相同 → 给出递进(默认浅、hover 中、active 深)
- 新令牌:
  - 深色:thumb `rgba(133,133,133,.35)` / hover `rgba(133,133,133,.6)` / active `rgba(133,133,133,.8)`
  - 浅色:thumb `rgba(0,0,0,.2)` / hover `rgba(0,0,0,.35)` / active `rgba(0,0,0,.5)`

### 3. 圆角优化 + 横向内边距
- thumb 圆角从 `--radius-sm`(2px)→ 改用 `8px` 让细滚动条更圆润(细条 2px 几乎看不出圆角)
- 加 `border: 2px solid transparent; background-clip: padding-box` 让 thumb 不贴边,视觉上更精致(像 macOS overlay 风格)

### 4. Firefox 兼容
- 全局加 `scrollbar-width: thin; scrollbar-color: var(--scrollbar-thumb) transparent`(当前只有终端有,且无颜色)
- Tauri 用 WKWebView(WebKit)所以 Firefox 规则主要为健壮性

### 5. Monaco 同步配色
- `theme.ts` 的 `scrollbarSlider.background/hoverBackground/activeBackground` 硬编码 hex → 与新令牌值保持一致(逐字同步,因为 Monaco 不能直接读 CSS 变量)

## 改动文件
1. **`src/styles/theme.css`**(2 处)
   - 深色 `:root` 块:更新 3 个 `--scrollbar-thumb*` 值 + 新增 `--scrollbar-size`
   - 浅色 `[data-theme=light]` 块:同上
   - 全局 `::-webkit-scrollbar` 块:width/height 用令牌 + thumb 圆角改 8px + 加 border/background-clip + 加 `* { scrollbar-width: thin; scrollbar-color }`
2. **`src/monaco/theme.ts`**(2 处)
   - 深浅主题的 `scrollbarSlider.*` hex 值与新令牌同步
3. **`src/monaco/theme.ts` getEditorOptions**
   - 加 `scrollbar: { verticalScrollbarSize: 8, horizontalScrollbarSize: 8 }`

## 不改动
- `.tabs`(3px)、`.breadcrumb`(0px)等特殊窄条保持
- 终端 `.xterm-viewport` 已有 `scrollbar-width: thin`,颜色会自动跟随全局 thumb
- xterm 不需要尺寸覆盖(继承全局 8px)
