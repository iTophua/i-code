# 文件树分支切换功能

## 交互设计（按反馈调整）
分支名直接显示在 `PROJECT_NAME` **右侧**，点击弹出分支下拉：

```
资源管理器          [图标按钮们]
PROJECT_NAME  ⎇ main ▾         ← 分支名紧跟项目名右侧
[筛选框]
[文件列表]
```

点击 `⎇ main ▾` 弹出分支下拉：
- 当前分支带 ✓
- 本地分支 + 远程分支分组
- 底部「＋ 新建分支」输入框
- 选中后 checkout → 自动刷新文件树

## 复用现有基础设施
- **Rust 命令**：`git_checkout`、`git_branches`、`git_checkout_new` —— 全部已注册
- **gitStore**：`branch`(当前分支)、`branches`(列表)、`loadBranches()`、`checkout()`、`createBranch()` —— 全部已实现
- **BranchManager 的 handleCheckout 逻辑**（远程分支创建本地跟踪）—— 抽取复用

## 实现步骤

### 1. 新建组件 `BranchSwitcher.tsx`
- 从 gitStore 读 `branch`(当前)、`branches`(列表)、`repoRoot`(判断 git 仓库)
- 弹出层用 Radix Popover（已有依赖）
- 下拉：本地分支组(当前✓) + 远程分支组 + 分隔线 + 新建分支输入框
- checkout 逻辑复用 BranchManager 远程分支处理（`replace("remotes/","")` → `createBranch(name, true)`）
- checkout 成功后额外调 `useFileTreeStore.getState().refreshTree()` 刷新文件树
- 非 git 仓库（`!repoRoot`）渲染 null

### 2. 接入 FileTree.tsx
- 修改 `.filetree__root` 行：项目名 + 内联 `<BranchSwitcher />`
- 仅 git 仓库时显示分支指示器

### 3. CSS（filetree.css）
- `.filetree__root` 改为 flex（项目名 + 分支指示器并排）
- `.branch-switcher`：分支标签 hover 高亮、箭头
- `.branch-switcher__popover/item/new`：弹出层复用 menu 风格

### 4. 文件树自动刷新
- checkout 后在回调里显式调用 `fileTreeStore.refreshTree()`

## 不改动
- Rust 后端、gitStore、BranchManager 保持不变
