# Tailwind v4 + shadcn/ui 全量迁移计划

## 一、总体策略

把现有的「16 个 CSS 文件 + CSS Variables + 手写 Radix 样式」体系，**全量迁移**到「Tailwind v4 CSS-first + shadcn/ui」体系。保留现有 CSS Variables 主题系统的色值（VS Code Dark+/Light+ 核对过的值），但用 shadcn 的变量约定重新组织。

## 二、分步实施（7 步）

### 步骤 1：安装 Tailwind v4 + shadcn 基础设施

**安装依赖：**
- `tailwindcss@4` + `@tailwindcss/vite`（v4 用 Vite 插件，不需要 PostCSS）
- `class-variance-authority`、`clsx`、`tailwind-merge`、`lucide-react`
- `tw-animate-css`（v4 动画）
- `tailwindcss-animate`（部分 shadcn 组件依赖）

**配置：**
- `vite.config.ts`：加 `@tailwindcss/vite` 插件
- 新建 `src/index.css`：`@import "tailwindcss"` + `@theme inline` 把 shadcn 变量映射到现有 `--bg-*/--fg-*`
- 新建 `components.json`：shadcn 配置（`-d` 默认值）
- 新建 `src/lib/utils.ts`：`cn()` 函数

**关键：变量映射**——把 shadcn 的 `--background`/`--foreground`/`--primary` 等映射到现有的 `--bg-editor`/`--fg-primary`/`--bg-button` 等，色值不变，shadcn 组件开箱即用深色主题。

### 步骤 2：用 shadcn CLI 添加组件

非交互式添加需要的组件：
```bash
npx shadcn@latest add button input select switch dialog dropdown-menu tooltip toast tabs checkbox -y -o
```
这些组件源码会落到 `src/components/ui/`（button.tsx、select.tsx 等），完全本地化可改。

### 步骤 3：迁移交互组件（优先）

把现有手写/Radix 组件替换为 shadcn 版本：
- `AppSelect.tsx` → shadcn Select
- `StatusBar.tsx` 的编码选择 → shadcn Select
- `SettingsPanel.tsx` 的 Select/Switch → shadcn
- `ConfirmDialog.tsx` → shadcn Dialog
- `AppContextMenu.tsx` → shadcn DropdownMenu/ContextMenu
- 删除旧的 `radix-theme.css` 属性选择器覆写

### 步骤 4：迁移布局组件（app.css → Tailwind）

逐个把布局 CSS 改为 Tailwind utility class：
- `App.tsx`（主布局）
- `ActivityBar.tsx` + CSS
- `Sidebar.tsx` + CSS
- `TitleBar.tsx` + CSS
- `EditorTabs.tsx` + CSS（tabs.css）
- `StatusBar.tsx` + CSS

### 步骤 5：迁移功能面板

- `FileTree.tsx` + filetree.css → Tailwind
- `GitPanel.tsx` / `BranchManager.tsx` / `CommitHistory.tsx` + git.css → Tailwind
- `SearchPanel.tsx` + search.css → Tailwind
- `NotesPanel.tsx` + notes.css → Tailwind
- `SettingsPanel.tsx` + settings.css → Tailwind
- `TerminalPanel.tsx` + panel.css → Tailwind
- `MarkdownPreview.tsx` + markdown.css → Tailwind

### 步骤 6：清理旧 CSS

- 删除 `src/styles/` 下被替换的 CSS 文件
- 保留 `theme.css` 的变量定义（作为 shadcn 变量的源头）+ Monaco/xterm 的特殊样式
- 删除 `src/components/ui/index.ts` 旧出口和 `radix-theme.css`

### 步骤 7：验证 + 打磨

- 全量构建验证（tsc + vite build）
- dev 启动验证
- 主题切换（深色/浅色）验证
- 所有功能回归测试

## 三、主题变量映射方案

现有变量 → shadcn 变量（在 `@theme inline` 里映射）：

| shadcn 变量 | 映射到现有 | 说明 |
|---|---|---|
| `--background` | `--bg-editor` (#1E1E1E) | 主背景 |
| `--foreground` | `--fg-primary` (#D4D4D4) | 主文字 |
| `--card` | `--bg-sidebar` (#252526) | 卡片/面板 |
| `--popover` | `--bg-menu` (#252526) | 弹层 |
| `--primary` | `--bg-button` (#0E639C) | 主操作 |
| `--secondary` | `--bg-tab-inactive` | 次要 |
| `--muted` | `--bg-list-hover` | 弱化背景 |
| `--muted-foreground` | `--fg-muted` (#858585) | 弱化文字 |
| `--accent` | `--bg-list-active` (#094771) | 强调/选中 |
| `--destructive` | `--fg-error` | 危险 |
| `--border` | `--border-base` | 边框 |
| `--input` | `--bg-input` | 输入框 |
| `--ring` | `--border-focus` | focus 环 |

这样 shadcn 组件用的 `bg-background`/`text-foreground` 等 utility 自动指向我们的 VS Code 配色。

## 四、风险与控制

1. **工作量大**：16 个 CSS 文件全改，分步推进，每步验证编译
2. **Monaco/xterm 样式**：这些第三方组件的样式保留在普通 CSS（`!important` 覆盖），不强行 Tailwind 化
3. **主题切换**：确保 shadcn 的 `.dark` 类机制和现有 `data-theme` 属性协调（用 `data-theme="dark"` 对应 shadcn 的 dark）
4. **不破坏功能**：先搭基础设施 + 迁移组件，确认无误后再清理旧 CSS

## 五、预期成果

- 所有交互组件（下拉/开关/对话框/菜单/提示）用 shadcn 精致版
- 布局用 Tailwind utility，更简洁统一
- 主题系统保留 VS Code 配色，支持深色/浅色切换
- 组件代码标准化、可维护性提升
