# 设置改为弹窗 + 快捷键 + 记忆分类

## 设计
将设置从"侧栏+主区"模式改为**居中弹窗**（Radix Dialog），左侧分类列表 + 右侧表单内容，类似 VS Code 设置弹窗。

## 改动步骤

### 1. 新增 SettingsDialog 组件
基于 Radix Dialog（复用 ConfirmDialog 的 `app-dialog-overlay/content/close` 样式模式）：
- 弹窗宽度更大（max-width 760px），内部左侧分类列表 + 右侧表单
- 分类列表复用现有 `SettingsPanel` 的 CATEGORIES 和逻辑
- 表单复用现有 `SettingsContent` 的 5 个子组件（ThemeSettings/EditorSettings 等）
- 右上角关闭按钮 + ESC/点遮罩关闭
- 复用 `.btn` 按钮样式

### 2. layoutStore 加 settingsOpen 状态
- 新增 `settingsOpen: boolean`（默认 false）
- `setSettingsOpen(open)` 切换
- `settingsCategory` 保持不变（记忆分类）

### 3. settingsCategory 持久化
- session.ts 加 `settingsCategory` key
- App.tsx 启动恢复 settingsCategory
- setSettingsCategory 时持久化

### 4. 快捷键 Cmd+, 打开/关闭设置
- App.tsx 全局快捷键加 `Cmd+,` → toggle settingsOpen
- 不再通过 setSidebarView("settings") 打开设置

### 5. 调整入口
- ActivityBar 设置按钮 → 改为 `setSettingsOpen(true)`（不再切 sidebarView）
- 命令面板"打开设置" → 改为 `setSettingsOpen(true)`
- 移除 sidebarView === "settings" 的特殊渲染分支（设置不再占用主编辑区）
- Sidebar.tsx 移除 "settings" case

### 6. CSS
- 新增 `.settings-dialog` 弹窗样式（更宽、左右分栏布局）
- 复用现有分类列表和表单样式

### 7. App.tsx 渲染
- 在 App 顶层渲染 `<SettingsDialog open={settingsOpen} />`
- 主编辑区始终渲染编辑器，不再被设置替换
