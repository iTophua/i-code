# i-code 主题系统规划

> 版本：v1.0 · 日期：2026-08-02
> 定位：VS Code Dark+ 风格的深色优先主题，支持浅色与自定义扩展

---

## 一、设计目标

| 目标 | 说明 |
|---|---|
| **深色优先** | 默认主题为深色（对标 VS Code Dark+），日常使用 |
| **熟悉感** | 配色、间距、图标风格对齐 VS Code，零学习成本 |
| **语义化变量** | 所有颜色通过 CSS 变量 + 语义 token 引用，换主题只改变量不改组件 |
| **可扩展** | 预留浅色主题、高对比度主题、用户自定义主题的接入点 |
| **Monaco 同步** | 应用 UI 与 Monaco 编辑器配色统一，切换主题时联动 |

---

## 二、主题架构

### 2.1 三层架构

```
┌─────────────────────────────────────────────┐
│  Layer 3: 命名主题（Theme）                  │
│   dark / light / high-contrast / 用户自定义   │
├─────────────────────────────────────────────┤
│  Layer 2: 语义 Token（Semantic Token）       │
│   bg.editor / fg.primary / accent / ...      │
│   组件只引用这一层，不碰具体颜色              │
├─────────────────────────────────────────────┤
│  Layer 1: 调色板（Palette）                  │
│   原始色值 #1E1E1E / #D4D4D4 / #569CD6 ...   │
└─────────────────────────────────────────────┘
```

- **Layer 1 调色板**：原始 hex，不直接在组件用
- **Layer 2 语义 Token**：按用途命名（`bg.editor`、`fg.muted`），组件统一引用这层
- **Layer 3 命名主题**：每个主题定义一套语义 Token 的具体值

> 这套分层是关键：换主题时只改 Layer 2 的映射，组件代码零改动。

### 2.2 CSS 变量挂载

```css
:root[data-theme="dark"] {
  /* Layer 2 语义 Token = Layer 3 dark 主题的具体值 */
  --bg-editor: #1e1e1e;
  --fg-primary: #d4d4d4;
  /* ... */
}
:root[data-theme="light"] {
  --bg-editor: #ffffff;
  --fg-primary: #1e1e1e;
  /* ... */
}
```

- 切换主题 = 切 `<html data-theme="...">`，CSS 变量自动切换
- Monaco 通过 JS API（`monaco.editor.defineTheme`）同步，监听主题切换事件

## 四、语法高亮配色（Monaco）

> 对标 Dark+ token colors。用于 `monaco.editor.defineTheme` 的 rules。

| Token 类型 | 色值 | 说明 |
|---|---|---|
| 关键字 keyword | `#569CD6` | 蓝（if/for/func/import） |
| 字符串 string | `#CE9178` | 橙红 |
| 注释 comment | `#6A9955` | 绿 |
| 数字 number | `#B5CEA8` | 浅绿 |
| 函数名 function | `#DCDCAA` | 黄 |
| 类型/类 type/class | `#4EC9B0` | 青绿 |
| 变量 variable | `#9CDCFE` | 浅蓝 |
| 常量 constant | `#4FC1FF` | 蓝 |
| 操作符 operator | `#D4D4D4` | 默认前景 |
| 标签 tag (HTML) | `#569CD6` | 蓝 |
| 属性名 attr | `#9CDCFE` | 浅蓝 |
| 默认/default | `#D4D4D4` | 主前景 |

**Monaco 注册示例**（实现时落地）：
```ts
monaco.editor.defineTheme('i-code-dark', {
  base: 'vs-dark',
  inherit: true,
  rules: [
    { token: 'keyword',      foreground: '569CD6' },
    { token: 'string',       foreground: 'CE9178' },
    { token: 'comment',      foreground: '6A9955', fontStyle: 'italic' },
    { token: 'number',       foreground: 'B5CEA8' },
    { token: 'type',         foreground: '4EC9B0' },
    { token: 'function',     foreground: 'DCDCAA' },
    { token: 'variable',     foreground: '9CDCFE' },
    { token: 'constant',     foreground: '4FC1FF' },
  ],
  colors: {
    'editor.background':     '#1E1E1E',
    'editor.foreground':     '#D4D4D4',
    'editorLineNumber.foreground': '#858585',
    'editorCursor.foreground':     '#AEAFAD',
    'editor.selectionBackground':  '#264F78',
    'editor.lineHighlightBackground': '#2A2D2E',
    'editorIndentGuide.background': '#404040',
  }
});
```

## 六、组件视觉规格

> 关键组件的视觉规格，写代码时直接参照。

### 6.1 活动栏（Activity Bar，最左图标条）

- 宽 `48px`，背景 `--bg-activity-bar`（#333333）
- 图标 `24x24`，颜色 `--fg-muted`（#858585）
- 激活态：图标变白 + 左侧 `2px` 强调色边条
- hover：背景 `#2A2D2E`，图标变 `--fg-secondary`

### 6.2 文件树（Explorer）

- 背景 `--bg-sidebar`（#252526）
- 行高 `22px`，字号 `13px`
- 选中：背景 `--bg-list-active`（#094771），文字白
- hover：背景 `--bg-list-hover`（#2A2D2E）
- 缩进每级 `8px`，带 `1px` 引导线 `#2D2D2D`
- Git 着色：文件名颜色用 `--git-*` token，状态字母在文件名右侧

### 6.3 编辑器 Tab

- 高 `35px`，激活 Tab 背景 = 编辑器背景（视觉一体），非激活 `--bg-tab-inactive`
- 激活 Tab 顶部 `1px` 强调色边条
- Tab 标题 `13px`，斜体 = 预览态（单击未固定）
- 修改未保存：Tab 标题右侧圆点（`--fg-accent`）
- 关闭按钮 hover 显示

### 6.4 底部面板（终端等）

- 背景 `--bg-panel`，顶部 `1px` 边框 `--border-base`
- 面板标题栏高 `35px`，激活标题带下划线强调色

### 6.5 状态栏（Status Bar）

- 高 `22px`，背景 `--bg-statusbar`（#007ACC 强调色）
- 文字 `--fg-on-accent`（白），字号 `11px`
- 左侧 Git 分支、右侧 编码/行尾符/语言/LSP 状态

### 6.6 按钮

- 主按钮：背景 `--bg-button`（#0E639C），hover `--bg-button-hover`，文字白
- 圆角 `--radius-md`（4px）
- 高 `26px`，内边距 `--space-3 --space-4`

## 七、Monaco 与 UI 主题同步

### 7.1 同步机制

```
用户切换主题
    │
    ├─ 更新 <html data-theme="...">  → CSS 变量切换 → UI 立即生效
    │
    └─ 调用 monaco.editor.setTheme('i-code-dark')  → Monaco 切换
```

### 7.2 实现要点

- 维护一个 `themeRegistry`，每个主题包含：CSS 变量集 + Monaco theme 对象
- 切换时：① 改 `data-theme` ② `setTheme` ③ 持久化到设置
- xterm 终端也同步：通过 `term.options.theme` 设置 ANSI 配色（用调色板对应值）

## 九、设置项

```jsonc
{
  "theme": "i-code-dark",          // i-code-dark | i-code-light | high-contrast
  "window.titleBarStyle": "custom", // custom | native
  "editor": {
    "fontFamily": "Menlo",
    "fontSize": 14,
    "fontLigatures": false,
    "lineHeight": 1.5,
    "minimap": true
  }
}
```

- 主题切换入口：命令面板 > "Color Theme" + 设置页下拉
- 主题数据存 `settings.json`
